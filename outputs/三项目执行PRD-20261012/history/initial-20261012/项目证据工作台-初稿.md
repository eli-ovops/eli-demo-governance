## 5. 数据模型、证据等级与版本

`schemaVersion = 1`；工具修订号与项目产品版本分别存，任何缺失值使用 `null/UNKNOWN`，不自动填当前日期替代历史证据日期。统一保存 ISO 8601 带时区时间，显示 Asia/Shanghai。首版对象如下：

| 对象 | 最小字段与约束 |
| --- | --- |
| ProjectCard | UUID、旧编号/别名、internalTitle/publicTitle、类型、参与期、主导/团队/UNKNOWN、roleStatements、ownerReference、唯一 activeAuthorityRef、工具 revision、归档标记。归属字段须携来源与确认日期。 |
| SourceRegistration | sourceId、locator、文件/目录模式、用途、metadataOnly/contentAllowed、类型/深度/数量/大小限额、授权人/日期、撤销时间。许可不是操作系统权限。 |
| EvidenceRef | evidenceId、sourceId、locatorHistory、原件/摘要/自述/Mock/装饰素材类型、证据日期、产品版本、检查结果/时间、可选 SHA256、文本定位/有限摘录、sensitivity、rights、reviewRecords。 |
| ClaimLink | claimId、projectId、维度、draftText、证据 ID 列表、局限、confirmer/日期；acceptanceResult 是关联证据快照的只读投影，携对应环境/版本/原件定位，不提供独立编辑验收状态的按钮；缺原件保留“历史结果说明”。 |
| AuthoritySnapshot | projectId、authorityRef、选定段落、capturedAt、sourceDate、sourceVersion/hash、读取范围、确认人；只追加，源变后标 stale，不能编辑成新事实。 |
| Revision/CheckRun | 递增 revision、前置 revision、变更字段、actor、时间；checkRun 保存选定范围、规则版本、成功/失败/取消项及时间，不存全文件正文。 |
| ExportManifest | exportId、schemaVersion、模式、项目/修订清单、generatedAt、批准公开字段版本、排除项、内容摘要；这是导出可核性记录，不是业务验收证书。 |

证据不是单一分数。分别展示四条轴：

1. **访问轴**：未检查 → 元数据存在 → 内容已读（全文/片段和范围）→ 人工原件复核。元数据存在不代表内容读取成功；人读确认与工具读成功分开。
2. **来源轴**：原始回执/日志、历史摘要、本人自述、AI 草稿、Mock、装饰素材。历史摘要不能升级成原件。
3. **业务轴**：每层独立 `UNKNOWN / 未验证 / 失败 / 部分通过 / 通过`，须环境、产品版本、日期、验收人及定位；本地通过不填设备/发布，哈希相同只说明字节一致。
4. **公开轴**：内部限定 / 待确认 / 指定用途已许可 / 撤销或过期；copyrightOwner、permissionEvidence、用途、截止日、确认人分别存。本人主导不自动取得截图公开许可。

新发现矛盾进入 gap，不平均评分、不用绿色总分掩盖缺口。人工复核只记本次覆盖范围，源变化/权限撤销令相应公开字段与证据复核待更新，历史记录保留。

## 6. 保存、导出、异常和原资产保护

建议工具数据与应用代码分开：项目根 `/Volumes/EXTERNAL/FDE/project-evidence-workbench/` 下未来建 `app/`、`server/`、`data/`、`exports/`、`evidence/`、`docs/`；`data/` 仅存索引/快照/修订和工具备份，`evidence/` 仅存本工具合成验收回执。原资料留原位。本轮以上除 docs 外均未创建；不得接用问卷 data、端口、会话秘密或 node_modules。

建议以一个完整 JSON 状态文件承载小型索引，单写队列 + 前置 revision 检查；写入前生成工具自身上一修订备份，写同目录新临时文件、校验并 sync 后再替换当前文件，完成适用的目录持久化。操作完成才显示“已保存”。并发第二实例拒绝写；锁残留不自动删除，先核原实例状态。保留修订与备份，不设自动清理策略。官方文档说明 Node 异步文件操作不提供并发修改同步，故不能用多个并行 writeFile 保存同一状态。[Node fs](https://nodejs.org/api/fs.html#promises-api)

建议限额：[Assumption] 状态包 10 MiB、登记 500 文件、单次检查 50 项、可摘录文本源 2 MiB/摘录 8 KiB。二进制只允许受控元数据；计算可选哈希必须明确请求且有单文件 20 MiB 上限，不读取数据库、秘密文件或云占位触发下载。超过限额提示分批/元数据登记，不静默截断证据，也不扩大扫描。

默认不跟随符号链接；路径组件校验、规范化与实际打开检查结合，拒绝 `..`、编码穿越、非普通文件与白名单外替换。`.env`、密钥、认证配置、cookie、数据库/备份及日志中秘密不进入索引正文；未知敏感文件只登记受限提示。权限拒绝后停止该项，不换工具绕读。网络地址仅保存用户选定的公开引用，P0 不自动请求或验证网站/平台状态。

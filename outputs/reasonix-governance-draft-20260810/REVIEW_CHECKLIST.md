# Reasonix 草案审查清单

状态：审查用；勾选不等于安装、生效或最终验收。

## 边界与授权

- [ ] 明确 Reasonix 只是 Codex 的辅助层，不是 PMO、Owner、授权来源或最终验收者。
- [ ] 确认权威顺序不会放宽平台、安全或当前用户的明确授权。
- [ ] 确认任务单与当前用户授权冲突或不明时必须停止，不能自行推断授权。
- [ ] 确认桌面端、来源不明和模式不明默认只读，且未声称可自动可靠识别桌面端。
- [ ] 确认 CLI 启动和 `--auto` 都不构成执行或扩权授权。

## CLI 任务信封

- [ ] `CLI_EXECUTION` 要求显式 mode、项目根、读/写 allowlist、允许命令、禁止项、验证、回报对象和停止条件。
- [ ] 缺关键字段时只能降级只读或停止；无写 allowlist 时绝不写入。
- [ ] allowlist 足够精确，命令参数、管道、重定向和子命令不会绕开边界。
- [ ] dirty worktree、并发冲突和未知改动的处理是停止与保留现场，不是覆盖、重置或回滚。

## 永久禁止项与防滥用

- [ ] 覆盖 PMO、最终验收、部署/回滚、migration、账号/权限、付款、删除、外部写入、secret、上位规则修改和 agent 指挥等永久禁止项。
- [ ] 覆盖静默安装/升级、网络探测、Git 提交/push、数据库/媒体、系统/VPN/代理等越界路径。
- [ ] 至少明确阻断：CLI 即授权、`--auto` 扩权、PMO 误派、静默安装、并发覆盖、自测冒充验收、secret 输出。

## 证据与采用决定

- [ ] 回报格式要求实际读取、改动、diff、命令与退出码、验证、未执行项、风险和 allowlist 外触及情况。
- [ ] 明确 HTTP 200、截图、build 或自述不能单独构成最终验收。
- [ ] 两个示例均不暗示自动授权或外部写入许可。
- [ ] 文本未含本机私密路径、项目 secret 或 Eli 专属事实；占位符可在其他项目复用。
- [ ] 若要生效，另行指定安装位置、适用范围、版本控制方式、Owner 和明确授权；本审查不替代该决定。
